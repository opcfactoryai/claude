以 REFERENCE_0 为基础，做以下根本性修改：

1. 构图与镜头：
- 拉远镜头，改为半身构图（腰部以上），不要近景特写
- 技师半侧身朝向镜头，脸可以不露全貌，侧脸或低头操作状态即可
- 重点放在场景空间感和氛围上，人物是场景的一部分而非主体

2. 场景与光影：
- 夜色灯光氛围：暖黄暗调环境光，从侧面窗或台灯方向打来
- 整体画面加一层轻柔朦胧感（微雾/暗角），不要锐利高清感
- 光线要有明暗过渡：人物一侧受光、一侧渐暗，有立体感但不刺眼
- 背景暗部自然隐去，营造静谧专业的夜间工作氛围

3. 皮肤与质感：
- 去掉客户皮肤上所有油光、高光反射、塑料感
- 皮肤改为自然哑光质感，保留真实毛孔纹理
- 肤色白皙但真实，有血色，不是假白
- 身材丰满但自然，不过分突出

4. 服装：
- 白色技师服保持素雅，棉质纹理
- 不过分贴合身体，自然垂坠

5. 整体基调：
- 主题是场景、构图、氛围
- 不是拍美人写真，不强调身材曲线、不诱惑、不媚俗
- 专业、克制、有质感的夜间工作场景

渲染风格：纪实摄影风格，自然光+单灯混合，胶片颗粒感轻微，画面有故事感而非商业广告感。
