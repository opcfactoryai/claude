# 京都三日古典慢走 · 旅行路线图

## 任务类型

旅行路线图（多日行程），复古手绘羊皮纸风格。

## 渲染 Prompt

生成一张京都三日古典慢走的旅行路线图，作为旅游攻略首图。

**整体风格**：复古手绘 + 淡墨水彩 + 米色羊皮纸底纹，温暖低饱和色调（焦茶、鼠色、薄墨、朱红点缀），画面有轻微做旧纹理与细腻花纹边框。整体如一幅旅行者手绘的羊皮卷地图。

**标题区**（顶部居中，手写体大字）：
- 主标题：京都三日古典慢走
- 副标题：電車 + 步行 · 寺廟庭園町家 · 西→東不回頭

**路线主体**（地图占据画面中央偏左 2/3 区域）：
- 交通方式：電車 + 步行
- 路线从画面左侧（西）向右侧（东）延伸，不回头，大致符合京都市地理方位
- 红线虚线代表电车路线，蓝色实线代表步行路线
- 三日站点如下，每个站点配一枚简洁手绘小插画（鸟居、五重塔、枯山水、竹林、町家格子窗、石灯笼、小桥等）：

  **D1 嵐山方面（画面最左）**：天龙寺 → 竹林小径 → 渡月桥 → 岚山站
  **D2 洛中·洛北（画面中部）**：金阁寺 → 龙安寺石庭 → 北野天满宫 → 二条城
  **D3 東山方面（画面最右）**：银阁寺 → 哲学之道 → 南禅寺 → 清水寺 → 二年坂/三年坂 → 祇园花见小路

- 站点以编号圆点（D1 / D2 / D3 分组，金色星 = 必去）标注，标签文字干净不遮挡路线

**侧栏**（画面右侧，约 1/3 宽，竖排羊皮纸条卷轴样式）：
- 每日要点列表，每天 2-3 条简短 bullet：
  - D1：岚山渡月桥晨雾 / 天龙寺曹源池枯山水 / 竹林小径穿行
  - D2：金阁寺金箔倒影 / 龙安寺石庭冥想 / 二条城鶯張り廊下
  - D3：哲学之道沿水漫步 / 清水舞台眺望 / 祇园傍晚町家灯笼

**图例**（左下角）：
- 红色虚线：电铁路线
- 蓝色实线：步行路线
- 金色星：必去景点
- 粉色花：拍照推荐点

**点缀元素**：复古罗盘一枚（右下角）、小段免责声明文字（画面底部边缘，极小字）、细微唐草花纹边框

**避免**：
- 城市/景点位置不能出现明显地理错误
- 标签不可遮挡路线
- 颜色不可过度饱和
- 线型不超过 2 种（仅红色虚线 + 蓝色实线）
- 不要画成精确比例尺地图，保持手绘插画感
- 侧栏文字密度不要高过地图本身
